# Contributing to Sorbus

## Reporting Issues

Found a bug or something not working as expected? Open an issue on GitHub and include:
- What you were doing
- What you expected to happen
- What actually happened
- Any relevant logs (check `server_output.txt` for C++ server logs)

## Contributing Code

1. Fork the repository
2. Create a branch for your change
3. Make your changes
4. Open a pull request describing what you changed and why

## Questions & Inquiries

For any questions, ideas, or general discussion, open a GitHub issue.

All contributions, bug reports, and communication should go through GitHub.
